# Match Preview / AI Commentary Design

**Date:** 2026-06-14
**Status:** Approved

## Goal

Add AI-generated match previews and post-match summaries to the Spielplan tab. Each match card gets a "⚡ Vorschau" button that expands an inline panel with German-language text generated by LiquidAI. Content is pre-generated daily by GitHub Actions and stored in `matches.json` — no runtime API calls from the browser.

## Architecture

Pre-generation fits the existing static-site architecture: a Python script runs in GitHub Actions, calls the LiquidAI API, writes two new fields to `matches.json`, and redeploys Pages. The frontend reads the fields and renders the panel. Zero runtime cost, zero API key exposure.

## Data Model

Two new optional fields added to each match object in `matches.json`:

```json
{
  "preview": "Deutschland und Brasilien treffen in einem Gruppenduell...",
  "summary": null
}
```

- `preview` — German pre-match text (2 sentences). Set when match is within 7 days and not yet started. Generated once, never refreshed.
- `summary` — German post-match text (1–2 sentences). Set after `status = FINISHED`. Displayed in place of the preview in the UI.
- Both default to `null`. Cards with `null` for both fields show no button.

**Generation rules (idempotent):**
- Match upcoming + `preview` is null + kicks off within 7 days → generate preview
- Match FINISHED + `summary` is null → generate summary
- Already has preview or summary → skip

| File | Action | Responsibility |
|---|---|---|
| `scripts/generate_previews.py` | Create | Pure functions + `main()` — call LiquidAI, merge into matches.json |

## Generation Script

`scripts/generate_previews.py` follows the same pattern as `update_scores.py`: pure functions at the top, `main()` at the bottom, exits 0 on API errors.

**LiquidAI API (OpenAI-compatible):**
```
POST https://labs.liquid.ai/api/v1/chat/completions
Authorization: Bearer $LIQUID_AI_API_KEY
Model: lfm-7b  (override via LIQUID_AI_MODEL env var)
max_tokens: 80
temperature: 0.7
```

**Prompts:**

Preview:
```
Schreib eine spannende Vorschau in 2 Sätzen auf Deutsch für das WM-2026-Spiel:
{home} vs {away}, {stage}, {date_de}. Nur die 2 Sätze, kein Titel.
```

Summary:
```
Schreib eine knappe Zusammenfassung in 1-2 Sätzen auf Deutsch für das
WM-2026-Spiel: {home} {homeScore}:{awayScore} {away}. Nur die Sätze, kein Titel.
```

**Pure functions (unit-testable, no API calls):**

| Function | Signature | Purpose |
|---|---|---|
| `needs_preview(match, now)` | `(dict, datetime) → bool` | True if upcoming within 7 days and preview is null |
| `needs_summary(match, now)` | `(dict, datetime) → bool` | True if match has scores AND kick-off was > 105 min ago AND summary is null |
| `build_preview_prompt(match)` | `(dict) → str` | Formats preview prompt string |
| `build_summary_prompt(match)` | `(dict) → str` | Formats summary prompt string |
| `merge_ai_text(match, field, text)` | `(dict, str, str) → (dict, bool)` | Returns updated match + changed flag |
| `call_liquid_ai(prompt, api_key, model, base_url)` | `(str, str, str, str) → str` | HTTP call, returns text or raises |

`main()` iterates all matches, calls `needs_preview` / `needs_summary`, calls `call_liquid_ai`, merges result, writes `matches.json` with trailing newline. Prints summary: `"Generated: 3 previews, 1 summary. Skipped: 44."` Exits 0 on API errors (transient).

## Workflow

`.github/workflows/generate-previews.yml`:

```yaml
on:
  schedule:
    - cron: '0 6 * * *'   # daily at 06:00 UTC
  workflow_dispatch:
```

Steps:
1. Checkout
2. Run `python3 scripts/generate_previews.py`
3. Detect changes: `git diff --quiet matches.json`
4. If changed: configure Pages → upload artifact → deploy Pages

Uses `LIQUID_AI_API_KEY` repo secret (separate from `FOOTBALL_DATA_API_KEY`).
Concurrency group: `preview-generation` (no cancel-in-progress — runs are slow and shouldn't be cancelled).

**Card template change** — button and panel added inside `<article>`:
- Button rendered only when `m.preview || m.summary` is non-null
- Button label: `⚡ Zusammenfassung` if `m.summary` exists, else `⚡ Vorschau`
- Panel label: `⚡ KI-Zusammenfassung` / `⚡ KI-Vorschau`
- Panel text: `m.summary ?? m.preview`
- Attribution: `LiquidAI` (plain text, no link)

**Click handler** (delegated on `#schedule-list`):
```javascript
if (e.target.classList.contains('preview-btn')) {
  e.target.closest('.match-card').classList.toggle('preview-open');
}
```

No additional state. Toggling `.preview-open` shows/hides the panel via CSS.

## Error Handling

- API call fails (network, rate limit, bad key) → log error, skip match, exit 0
- API returns empty or malformed text → skip that match (don't write empty string)
- `matches.json` unchanged → workflow skips Pages deploy

## Testing

`scripts/test_generate_previews.py` — pytest, tests pure functions only (no API calls):
- `needs_preview`: upcoming within 7 days with null preview → True; already has preview → False; > 7 days away → False; FINISHED → False
- `needs_summary`: has scores AND kick-off > 105 min ago AND summary null → True; already has summary → False; no scores → False; too recent → False
- `build_preview_prompt`: contains home team, away team, stage
- `build_summary_prompt`: contains score, both team names
- `merge_ai_text`: returns updated dict and `changed=True`; does not mutate original
